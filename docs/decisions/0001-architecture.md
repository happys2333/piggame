# ADR-0001：数据驱动、离线优先的 Godot 架构

## 决定

- 以一个 `GameSession` Autoload 作为应用门面，UI 只能调用其命令和订阅其信号。
- 时钟、状态、模拟、行为、事件、内容和存档保持可独立测试的小模块。
- 内容使用版本化 JSON，所有对象具有永久 ID，所有可见文本只保存本地化键。
- Steam、音频与桌面窗口分别放在适配层，核心模拟不依赖平台 API。
- 猪咪和房间使用可复用的 2D 部件/程序绘制视觉，事件由步骤数据驱动，避免 24 个独立硬编码脚本。

## 原因

该结构直接对应策划案模块边界，允许无 Steam 环境测试，并让新增事件主要成为数据工作。单人项目仍保持模块数量受控，不引入服务器、数据库或通用 ECS。
