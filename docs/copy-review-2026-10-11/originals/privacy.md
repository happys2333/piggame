# Privacy statement

## 简体中文

《猪咪今天也没干嘛》不要求账号，不接入广告 SDK，不运行自建服务器，默认不收集或上传个人数据。养成存档、截图、机器设置和最多 5 份滚动运行日志保存在玩家设备上；日志只供玩家主动反馈崩溃，不会自动上传。Steam 云存档启用时，只同步养成存档、两个安全备份和游戏自动生成的生活相册照片；不同步显示器、窗口位置、分辨率、手动截图、导出副本或日志，其传输由 Steam 平台处理。正式版和 Demo 使用互相隔离的云路径。

桌面防打扰仅接收本游戏窗口/应用的焦点通知，不识别其他游戏、不扫描进程、不读取其他窗口或桌面、不监听全局键鼠、不捕获系统音频或麦克风。只有发送给本游戏的主动输入才用于即时反馈，输入内容不记录、不上传。专注计时只在内存中存在，不保存工作时长历史；安静、勿扰、行为频率保存在机器设置中，不进入云存档。

## 繁體中文

《豬咪今天也沒幹嘛》不要求帳號，不接入廣告 SDK，不運行自建伺服器，預設不收集或上傳個人資料。養成存檔、截圖、機器設定和最多 5 份輪替執行日誌保存在玩家裝置上；日誌只供玩家主動回報崩潰，不會自動上傳。啟用 Steam 雲端存檔時，只同步養成存檔、兩份安全備份和遊戲自動生成的生活相簿照片；不同步顯示器、視窗位置、解析度、手動截圖、匯出副本或日誌，傳輸由 Steam 平臺處理。正式版與 Demo 使用互相隔離的雲端路徑。

桌面防打擾僅接收本遊戲視窗/應用程式的焦點通知，不識別其他遊戲、不掃描程序、不讀取其他視窗或桌面、不監聽全域鍵鼠、不擷取系統音訊或麥克風。只有傳送給本遊戲的主動輸入才用於即時回饋，輸入內容不記錄、不上傳。專注計時只存在記憶體中，不儲存工作時長歷史；安靜、勿擾、行為頻率儲存於機器設定中，不進入雲端存檔。

## English

The game requires no account, includes no advertising SDK, uses no first-party server, and does not collect or upload personal data by default. Progress saves, screenshots, machine settings, and up to five rolling runtime logs remain on the player's device; logs are only for player-initiated crash reports and are never uploaded automatically. When Steam Cloud is enabled, it synchronizes only the progress save, two safety backups, and game-generated life-album photos. Monitor, window-position, resolution, manual screenshots, exported copies, and logs are excluded; transfer is handled by Steam. The full game and Demo use isolated cloud paths.

Desktop protection only receives this game's window/application focus notifications. It does not identify other games, scan processes, read other windows or the desktop, monitor global input, or capture system audio or microphones. Deliberate input delivered to this game is used only for immediate feedback and is never logged or uploaded. The focus timer stays in memory and keeps no work-duration history. Quiet, do not disturb, and frequency preferences remain in machine settings and are excluded from cloud saves.
