# 图内文字与非本地化标记

八张现有PigHub原图逐一人工查看。标题/信件在主CSV内；下面是位图自身文字，不能通过翻译表修改。不修改原图、水印或来源声明。细字无法可靠辨认时明确保留未知。

锁定表情的 `?` 属于绘制标记，不是缺失译文；操作系统/Godot提供的原生菜单不是本地化CSV内容。其他生成角色、家具和UI图标不是本轮可编辑文案表；若发现位图里的装饰字形需另外看图确认。
