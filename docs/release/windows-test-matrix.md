## 性能证据要求

- 使用 `tools/windows_runtime_probe.ps1` 分别采集 `main-room`、`desktop-active`、`desktop-idle`，每个短场景至少 120 秒；桌面静止平均 CPU 必须 `<2%`，桌面活动平均 CPU 必须 `<5%`，所有场景峰值工作集必须 `<300 MiB`。
- 每份 JSON 必须包含本页记录的候选 SHA-256、Windows 版本/构建号、CPU、GPU、逻辑处理器数、逐次样本和严格预算结果。
- 使用 `tools/validate_windows_probe.py --expected-exe <同一候选> <证据 JSON...>` 复算全部指标；校验器通过后仍需在矩阵“证据”列填写 JSON 文件名。
- 主屋 CPU 没有策划案阈值，不得把桌面 `<5%` 门槛套到主屋；主屋 60 FPS 另用 Windows 帧率工具或录屏帧时间留证。
- 2/8/24 小时运行分别使用 7,200/28,800/86,400 秒采样；睡眠、休眠、锁屏、切换用户和系统时间变化需另记操作时间、恢复结果以及是否出现补播动画或重复离线结算。
