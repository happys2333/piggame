# 用户委托生成的视觉资源

用户于 2026-10-05 明确要求“替换所有现有素材，调用 image gen 去生成我们需要的美术资源”，因此此前图片创作冻结对本次视觉任务不再适用。音频不在 image_gen 的能力或本次视觉授权范围内，仍保留原合成占位并强制静音。当前状态不是最终发行验收通过。

## 文件与复用

- 运行原图：`game/assets/final/generated/`。
- 完整生成提示词及原工具输出路径：`docs/design/generated-art-prompts.json`。
- 永久 ID、原图 SHA-256、图集区域、动作帧和附件落位：`game/data/catalog/final_asset_manifest.json`。
- 重新逐字节复制并打印路由清单：`python3 tools/build_generated_visuals.py --copy`；该工具不改写 PNG、不绘图、不合成、不转码，不调用任何付费外部 API。
- 单独验证视觉：`python3 tools/validate_generated_visuals.py`。
- 隔离式四帧渲染回归：`python3 tools/run_ui_smoke.py --generated-art-regressions`，不会覆盖完整 UI 截图证据。

生成工具不保证提示词要求的像素尺寸，所以清单使用每张实际 PNG 的宽高划分区域，不假定全部是 1024 像素。`AtlasTexture.filter_clip` 防止邻格采样，附件用原图 alpha 范围定位再配置逻辑 280×230 画布中的位置。照片相框的三个中心都验证为 alpha 0。原始文件保留生成器输出的完整字节；图集裁切只是运行时区域引用。

动作帧使用已有 0.1 秒视觉步进，不改变模拟、收益、冷却、存档或事件节奏；“减少动态”固定首帧，桌面暂停沿用已有时钟门禁。完整角色表情替换整个角色层，避免把整只表情猪重复贴到脸上；既有用户交付的小型肖像仍沿用原局部覆盖接口。

## 渲染回归修复

新角色图集的空白区域含低 alpha 残影，50% 缩放时被颜色量化抹去，导致像素边界不再与 100% 成比例。两次 image_gen 清理尝试仍有残影，未采纳，来源和提示词作为 rejected_variants 留存。运行 PNG 仍是最初生成器的原字节。每帧依据 alpha ≥ 8 的内容边界加一像素安全边界产生 `frame_trims`；`AtlasTexture.margin` 保留原格尺寸和落位，只停止采样空白外围残影，不改写、转码、绘制或合成 PNG。专门回归覆盖四帧、五档缩放及两个房间往返布局；原像素边界容差未扩大。

自动照片的差异仅为少量纹理像素的一位色值，来自把舞台平移到较小离屏视口后的浮点采样精度变化。捕获改用原主视口尺寸、比例和坐标网格独立绘制舞台，再裁剪实际照片区域，仍不读取叠加 UI。原逐字节像素断言保留，关闭/F3/缩放/桌面交接及取消路径继续验证。

## 发行边界

2026-10-06 验证完成：核心 6099、UI 2230、四帧专项 768、Python 106、实际 Demo profile 71、两套节奏、视觉及内容校验通过。完整 UI 的 137 张截图通过 90 秒库存门禁；四档主窗口布局已查看。Full/Demo 验证 ZIP 与 Windows EXE 严格串行重建，两包审计及隔离启动确认全部 179 个视觉路由可解析。新候选身份以 `docs/release/candidate-manifest.json` 为准。

`visual_ready=true` 与 `generation_authorized=true` 只允许完整视觉覆盖进入游戏。`ready=false`、`provided_by_user=false` 不变，不把委托生成的结果说成用户提供的原创源文件，也不预先保证独占版权、商标或最终发行权属。完整最终素材校验继续因为 34 项音频、用户交付/权属等门禁未齐而失败。

旧程序绘制只作为错误降级，旧 Noto 上游母版及许可证保留为来源归档，未从玩家目录删除任何文件。Windows 实机、Steam、外部玩家、三语人工校对、最终音频舒适度等验收仍未完成；静音开发候选不启动最终七天发布倒计时。
