# 猪咪生活手账：原生 UI 重设计

## 设计规格

用途是观察、陪伴和收藏，不是管理仪表盘。猪咪保留主舞台，常用操作成为轻量工具；详细内容仅在玩家打开时出现。主题是玩具式生活手账与纸质明信片，保留原有猪主体和小屋，不替换美术，不引入解释段落。

- 色板：纸白 `#FFFDF7`、墨色 `#2B3030`、草莓粉 `#EF7390`、抹茶绿 `#60765B`、纸边 `#E6E4D9`。粉色来自猪的主体，绿色用于已选/已拥有状态；不是紫色渐变或通用 SaaS 配色。
- 字体：霞鹜文楷用于主要标题，Noto Sans SC 用于正文、按钮、数值。30/20/16/13 层级，长名字省略并保留完整提示，正文优先可读。项目内离线字体及许可单独记录，子集不冒称上游原字节文件。
- 主场景：左上身份与状态的小型签牌、右上点数与工具；底部紧凑工具坞。HUD 不占满一整行高大按钮，中央留给猪和家具互动。
- 内容层：实色纸白，不让背景猪的五官穿过正文；外层轻阴影、内层细纸边，按钮、卡片、纸页不使用同一个圆角。
- 相册：宽窗口采用左侧五类导航与右侧收藏页；较大字号时导航变成紧凑横排，保留文字提示和无障碍名字。现有五页、永久 ID、未读标记和读取事务保留。
- 商店：更大的等比物品展示、清晰名称与短描述，购买、使用、已穿戴、解锁条件有不同层级，不把所有状态画成灰色禁用块。
- 设置：按外观、游戏、音频归组，快捷入口与开关分层。细滑轨、线性图标、可识别选中态与键盘焦点；低对比的 Godot 默认灰色状态不再泄露到界面。
- 图标：Lucide 统一线性图标，不拿 emoji 拼 UI。来源固定提交与修改说明记录在许可目录。

## 实现边界

Godot 4.6 原生 Control/Theme/Container，不引入浏览器/WebView/在线字体。使用已安装的 Anthropic 官方 `frontend-design` 的视觉层级/节制原则，结合现有 `godot-ui` 的原生布局规则；Web 样式建议不照搬成网页游戏。手账的纸白与粉色是本游戏实体与信件的材料语义，不采用 Anthropic 土橙品牌配色。角色图片、比例、动作、点数、离线收益、存档和后台防打扰不改变。

先完成组件、HUD、相册和设置的整套实现，再集中执行真实截图/交互与兼容验证。1280×720、16:10、超宽、80%/150% 与三语均检查；Full/Demo 串行导出加载。本机渲染不替代 Windows 实机验收，最终素材门禁状态不变。

## 实装与核验

- 原生 HUD、工具坞、物品分类、相册五类导航、双栏信件、设置分组、住客表单与桌面控制条已重排。窗口调整和字号调整后的布局会重算；已选导航保留原页序，键盘焦点落在当前页。
- 使用截图先发现并修复了收缩按钮挤掉图标、住客单卡过窄、大字号相册留白、英文快捷入口截字和桌宠控件超出固定点击区的问题。全部角色与物品位图保持原样，未重新生成或修改猪主体。
- 两个离线字体子集合计约 6 MiB，28 个线性图标；大型原字体不进入包。字形覆盖、许可、来源哈希和文案相关的 30 项 Python 检查通过，内容校验通过。
- `build/validation/ui-redesign-verified-20261009/`：9483 项新版原生 UI 检查通过，171 张真实截图；覆盖三语、720p、16:10/80%、超宽、150%，五页导航、实色背景、全屏往返和桌宠 50/75/100/125/150% 普通小窗控件/原生点击区匹配。确认窗口重排后真实开关仍反映保存设置，不使用已释放的旧控件引用。
- `build/validation/ui-redesign-postcards-20261009/`：信件专项 596 项检查、67 张截图通过，含 960×540/150%、三语原图等比展示、持久化拆信、滚动返回和后台防打扰。该证据早于最终桌面控制条主题微调；最新页面证据以前一目录为准。
- 核心规则 7080 项、Full/Demo 进度与 Demo 配置检查通过；日志保留在 `build/validation/ui-redesign-20261009/headless.log`。最终素材门禁按预期失败，音频仍静音占位，不作为发行候选。

### 全量回归限制

这不是一次全量 UI smoke 通过报告。首轮完整 smoke 的 4153 项断言中有 212 项失败，并有测试持有全屏重排前的旧控件引用错误。完整原始日志保存在 `build/validation/ui-redesign-20261009/full-smoke-failed.log`。

与新 UI 相关的标记色、五页索引、最小窗布局与重排引用断言已更新；全屏往返、原生控制条尺寸和新版页面已有上述专项核验。完整 smoke 中还出现桌宠/物品交互几何、触控、原生透明状态、照片取景与家具轮廓方面的失败，需要独立复查；没有删除这些保护断言，也没有宣称它们已通过。Windows 原生实机尚未验证。
