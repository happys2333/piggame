# 主动互动音效接入（无 BGM）

## 当前决定

用户于 2026-10-12 批准接入生成音效，并明确不需要背景音乐。本次取代此前冻结/全程静音的音频开发决定；不把生成输出标记为用户原创，不把接入批准标记为最终发行批准。

从 ComfyUI Cloud Run 候选选入 13 个短音效，总线仅 Interaction；不创建音乐/环境声播放器。音乐、雨声、风铃及暂未使用的洗澡/挠痒/脚步留在 `.gdignore` 候选目录，不进入发行。旧 music/sfx 占位目录通过 `.gdignore` 排除导入、导出，保留历史可恢复性。音频 ID 保留/下架记录见运行清单 `retired_ids`；它们不写入养成存档。

`audio_candidates/` 试听包和母带仅保留本机，排除 Git；Windows 拉取只需已接入的 `game/assets/audio/feedback/`、来源清单及代码，不需要下载未使用的 BGM/母带。`build/` 中验证证据和存档恢复副本同样不入库。

## 路由

| 主动操作 | 反馈 |
|---|---|
| 普通按钮 | ui_click，延后一帧作为语义反馈的低优先级回退 |
| 主动展示动作 | ui_switch |
| 摸头 | pet_content；社恐/傲娇使用 pet_shy |
| 戳脸 | pet_question |
| 投喂 | bite；莓莓奶使用 sip |
| 穿戴/卸下头脸饰品 | accessory |
| 主动购买 | unlock |
| 主动邀请使用家具 | 休息类 blanket，其他 soft_bump；不循环播放 |
| 主动放下猪咪 | soft_bump |
| 首次拆开明信片 | postcard；自动到达无声音 |
| 主动截图成功 | camera；小剧场自动拍照无声音 |

自动行为、点数、升级、事件收尾、离线结算、自动动作、寄信及专注提醒不请求音效。小剧场时间轴不发声，避免用户切走后继续或补播。发声入口默认 autonomous 并拒绝，只有明确 player 调用有资格。

## 打扰与资源控制

- 失焦、隐藏、最小化、安静、勿扰、关闭音效或音量为零时不发声；保护变更立即停掉现有声音，回来不补播。不读取其他应用/游戏或进程。
- 默认音量 65%，最多三路；全局 140ms、同音 500ms 冷却。满池直接丢弃，不排队、不抢占。WAV 按需缓存且不循环，保留混音余量。
- 设置只保留音效音量、关闭音效和手动试听；桌面右键可关闭音效。旧音乐/环境音设置忽略，旧互动音量保留；机器设置与养成档仍分离。
- 购买/投喂/穿戴/首次拆信在存档成功后反馈，失败不播放成功声音。截图按钮不叠加点击声。
- headless 生产节点永远不输出；专项仅在隔离 Dummy 夹具验证播放器，不代表扬声器验收。

## 验收边界

专项：`python3 tools/audit_audio.py --output build/validation/sfx-integration-20261012`。历史占位循环失败不改成通过，而是随 BGM 需求撤销下架，原证据仍在 `docs/design/audio-audit-2026-10-12.md`。最终素材门禁继续失败；Windows 原生声音、设备切换和主观听感仍待验收。旧 EXE/candidate-manifest 是历史静音包，不自动代表本次代码。

## 本轮证据

- `build/validation/sfx-integration-20261012/passed/`：13 文件及生成来源哈希匹配，230 项 Dummy 路由/策略/限频/中断/存档事务断言通过。最大音量三路同相峰值上界 −11.468 dBFS，非实际扬声器混音测量。
- `build/validation/sfx-integration-20261012/final/`：核心 7053 项、正式版进度、Demo 30 分钟包络通过；设置覆盖三语言及 720p、16:10、超宽、80%/150% 共 15 种布局。Full/Demo ZIP 串行导出，各约 25.07 MiB，通过包资源核验和隔离加载。不是 Windows EXE 实机验收。
- 最终资产门禁退出 1：仍缺 13 个最终音频覆盖标记与用户原创/最终批准，符合当前非发行状态。
- 首次 Full ZIP 加载的 override 放错目录，探针拒绝前曾触发普通主档离线结算。已按原 rotating backup1 原字节原子恢复主档，机器设置未变；运行前后副本及恢复哈希保留在 `build/validation/sfx-integration-20261012/save-recovery/`，不声称备份轮转历史完全未动。后续把 ZIP 与 override 放在同一隔离目录，Full/Demo 均重测通过，不再重复结算。
