# 慢慢来小计划

2026-10-07 用户要求继续丰富放置玩法。本轮补充选择目标 → 布置房间 → 自主生活/离线推进 → 收集永久手账的轻量闭环，复用既有动作和美术，不生成或启用音频。

## 产品规则

- 六本计划：枕头研究、零食评测、轻运动、午后阅读、窗边观察、小屋远征，分别在熟悉度 2/3/4/5/6/8 开放。Demo 保留枕头研究。
- 每本有三个永久 ID 的手账条目，累计灵感时间达到 10/40/90 分钟时记录。全部六本共 18 段原创短记。
- 一次只选一本。随时暂停、换本、继续；各本进度和已记录条目独立保留，没有自然日重置、期限、签到、失败、退步或领取窗口。
- 仅真正摆进房间的对应家具提供每件 20% 灵感速度，最多两件；拥有但没摆出的家具不生效。完成对应标签的自主行为另贡献 10 秒灵感，邀请、取消或重复打开界面不贡献。
- 在线、桌面和离线都按已选计划推进。离线只用 `GameClock` 已认可的至多 24 小时区间和已保存的房间布置，不编造看过的行为，也不改变离线点数。到终点后停止，不擅自替玩家换下一本。
- 手账是纯纪念，不发点数、熟悉度、家具或成就，不改变现有 15/30 分钟引导、8–20 小时主线及 20–40 分钟 Demo 节奏。无须盯着计时或频繁点击。

## 工程边界

- 内容在 `game/data/catalog/life_plans.json`；`LifePlanRules` 只计算灵感、阈值与条目，不依赖窗口或 Steam。
- `PigState` 保存当前选择、各本累计进度、永久条目 ID。schema 4 中新增可选字段，旧 schema 0–4 缺失字段默认空，不强转损坏字段来绕过验证。
- `SaveService` 校验类型、有限数值、边界、永久 ID 和条目对应的已完成进度，沿用原子写入与两份轮换备份。选择、暂停和在线新条目提交失败时回滚；条目保存重试限频，恢复后可继续。
- UI 在相册新增“小计划”页，全部写操作通过 `GameSession`。只刷新当前页的进度控件，不弹出完成窗口、不刷新桌面回忆气泡、不修改行为调度或事件条件。
- 使用已生成的角色动作作为计划插图。所有标题、说明、手账与状态走三语本地化键。
