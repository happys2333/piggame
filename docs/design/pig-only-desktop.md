# 单独桌宠

2026-10-07 用户要求猪咪可以独立、透明、无边框地留在桌面。保留小屋玩法和普通小窗降级，不增加通知、签到或离开惩罚。

## 操作

- 从主界面的桌面入口进入，在 `⋯` 菜单开启“只显示猪咪”。透明支持正常时，原生窗口无边框、背景透明，控制条与回忆气泡完全隐藏。
- 右键猪咪显示独立菜单，包含返回小屋、缩放、停靠、置顶、专注、暂停、透明切换、最小化和退出。`Esc` 恢复控制条；回忆仍保留在相册，不因隐藏气泡丢失。
- 鼠标或触控移动超过 8 px 后请求 Godot 4.6 原生窗口拖动并取消当前互动，避免拖动变成摸摸奖励。该路径只在单独桌宠模式执行，Windows 鼠标/触控原生拖动仍待真实设备确认。
- 不支持透明或关闭透明时使用有边框的普通小窗。始终能通过右键返回小屋或恢复控制条，不把透明作为启动条件。

## 工程边界

- `desktop_pig_only` 是机器本地设置，默认关闭，严格校验布尔类型。存档进度、小计划、事件条件和经济均不受模式切换影响。
- `DesktopFramePolicy` 为五档缩放计算无控制侧栏的窗口尺寸和猪咪最小可达区域。输入穿透仅保留猪咪矩形，不把隐藏按钮/气泡及连接走廊留在捕获区。
- 截图可见性恢复不能意外显示隐藏的桌面控件。多屏恢复检查猪咪可达矩形；屏外时回到有效显示器工作区。
- 保留活动 30 FPS、静止/暂停 12 FPS、减少游走和降低动作频率设置。在线与离线养成规则保持一致。

## 验收

核心几何/输入信号和真实渲染 UI 烟测覆盖紧凑尺寸、透明角、原生无边框属性、右键菜单、Esc、重进持久化与返回小屋。合成输入验证不代替操作系统原生拖动；Windows 10/11、DPI、多屏、透明穿透、任务栏与触控须保留未测状态，见 `docs/release/windows-test-matrix.md`。
