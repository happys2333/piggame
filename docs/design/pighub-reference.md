## 文案落地

学习“猪 + 日常情绪/词语错位”的结构，不声称下列新文案逐字来自网站。为小计划原创七处短梗：猪要课题、高枕无猪（猪在，忧不在）、食不相瞒、猪动休息、胸有成猪/猪意、猪光宝气、猪持大局。

- 放在永久手账中，玩家自己打开才读到，不增加桌面气泡、弹窗或重复通知。
- 每段仍讲清楚具体日常，不让谐音替代按钮含义、规则说明或错误信息。
- 简繁体保留中文谐音；英文单独适配 `pig-ject`、`snoutstanding`、`hogging the map` 等轻量双关，不逐字硬译。
- 不改变永久内容 ID、门槛、经济、存档字段或 Demo 范围。
