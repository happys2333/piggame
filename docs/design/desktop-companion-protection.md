# 桌面防打扰与专注陪伴

## 不识别游戏，默认保护所有其他应用

只接收 Godot 本窗口/应用的焦点通知。启动时默认保护，直到根 Window 的 `has_focus()` 确认；应用焦点进入也必须经过根窗口确认。失焦立即清除短期反馈许可、撤销有效置顶、隐藏现有提示与回忆气泡，冻结桌宠自主姿势、四帧推进和漫步。底层养成、奖励、小计划与正常运行时计时继续；没有缺席惩罚。机器保存的置顶偏好不变，回来时才恢复有效偏好，手动勿扰仍优先。

这比仅识别特定游戏更保守：浏览器、编辑器与其他游戏都不会被主动打扰。没有进程扫描、全局输入钩子、系统空闲检测、第三方窗口读写、音频捕获或桌面截图。鼠标经过和键盘重复不算主动互动。

## 用户主动反馈不是解除保护

本窗口真实点击、触控、非重复按键和明确菜单/按钮操作允许短期反馈；取消与模拟鼠标事件不产生重复许可。它不会触发策略变更，不重置行为间隔、不恢复漫步/帧动画、不打开主动回忆气泡。自动行为点数、自动升级、回忆等待和结局/试玩完成提示不能借用该许可。再次失焦清空许可，即使此前已经在后台。恢复不补发过期提示，也不补播旧自主动作。

安静模式停止主动动作/提示；勿扰同样停止并撤销置顶。频率提供自然切换、至少 45 秒、至少 120 秒和关闭；默认 45 秒，旧“降低动作频率”仍是最少 45 秒的下限。暂停动画和上述保护均优先；明确解除暂停只呈现当前最新动作。

## 25/5 专注

专注 1500 秒呈现既有读书素材，用户主动开始 300 秒休息时呈现既有拉伸素材。计时与模拟分开，无点数/熟悉度奖励或考核。支持暂停/继续/停止，到点不弹窗、不发声、不抢焦点。仅本应用前台且没有安静/勿扰/关闭主动行为时发一次轻提示；后台到点直接消费，不在回来后补发。长于运行时恢复阈值的睡眠停顿只进行原有离线结算，不算工作时间。

计时、焦点和输入许可不持久化，没有工作时长历史。偏好仅写机器设置，失败整组回滚，不修改养成档。参数和动画路由集中于 `game/data/catalog/desktop_companion.json`；三语文案与内容门禁同步，UI 操作经 GameSession。

## 验证边界

新增政策组合、25/5、间隔、保存回滚和恢复停顿回归，以及实际渲染的冻结像素、置顶撤销、菜单/设置、主动输入和三语五档布局回归。自动化仅是 macOS 可控焦点/合成通知与输入证据，不证明 Windows 游戏独占全屏、无边框全屏、真实 Alt-Tab、触控或原生弹出菜单的事件顺序。发行前必须完成 Windows 矩阵相应项目；不得宣称所有游戏/系统已兼容。

本轮复用已有读书/拉伸素材，未引入新美术。嘴部修正版情绪图集仍在审查目录，尚未接入运行资源，不视为最终发行批准。系统音乐反应、全局光标追逐、系统空闲检测、第三方窗口趴边和桌面合影尚未实现。
