# 独立猪猪性格

## 初始选择

首次命名和新住客表单默认“随机遇见”，也可明确选择活泼、傲娇、懒惰、社恐或贪吃。随机在真正提交时等概率生成，不因打开表单、选择预览、切换、改名或重启而反复抽取；没有稀有度、属性强弱或付费门槛。跳过教程/不填写首只名字仍保存选择。正式版与 Demo 共享五种性格。

每只保存永久 `personality_id`，与名字和养成资料一起置于原子主档和两份轮换备份。接纳、初始设置或旧档补选失败时回滚，不显示虚假成功或留下半个名字/性格。选定后不可通过初始接口重抽；改名接口只改名字。

## 可观察但不增加负担

性格改变明确摸头/戳脸时的临时表情和口吻：活泼开心贴贴，傲娇嘴硬，懒惰打哈欠，社恐小声回应/惊讶，贪吃联想饼干。复用既有生成表情资源，不新增纹理或混入未经审查的嘴部图集。这些短反馈不自动解锁对应收藏。

点数、熟悉度、需求消耗、照顾频率、行为权重、离线收益、小计划、事件和进度节奏都保持原样。贪吃不多消耗食物，社恐不要求额外陪伴，傲娇不惩罚互动。后台/安静/勿扰仍优先；性格反馈只响应明确互动，不新增主动弹窗、声音或全局检测。

## 旧档与多猪

保持 schema 4，新增可选字符串字段。缺少字段/空字符串表示未选择，保留原来普通反应，不在载入时随机改变老猪。旧档在住客页可补选一次，不选也能继续。载入缺少字段时明确清空内存中上一只的性格，避免跨猪继承。

已选字段只允许五个永久 ID；随机选项不是存档 ID。非法类型或未知 ID 会使当前整组存档无效，恢复合法备份而不是悄悄改成另一种性格。非当前猪也参与校验，顶层当前镜像必须一致。Demo→正式版迁移保留原性格。

内容集中于 `game/data/catalog/personalities.json`，包括本地化键、两种互动表情 ID/分类和口吻。内容门禁禁止经济属性或错配表情。UI 经 GameSession 完成设置，随机源可注入以便回归测试，不保存随机历史。

## 验证范围

核心覆盖五种选择/反馈、随机覆盖与确定性、独立住客、重载/改名保持、旧档兼容、非法字段、整组备份恢复和失败回滚。真实 UI 覆盖初始随机默认、教程跳过、自选与新住客、五种不同角色像素，以及三语/80%/150%最小窗口。Windows 原生下拉菜单、输入法、DPI、文件共享/云同步仍需实机验收，本机渲染与合成操作不代替这些证据。
