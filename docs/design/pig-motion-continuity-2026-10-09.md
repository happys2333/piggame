# 猪宠连续表现与实际美术检查

2026-10-09：用户再次反馈偶发变形，并要求真实测试、截图检查全部美术。本记录替代同日早先的“CDF 网格形变通过”结论。

## 已复现的问题

基线真实 Godot OpenGL 渲染的 70 项检查失败 68 项。朝向从 +1 插值到 -1 导致中途零宽；独立原稿的透明轮廓并非解剖对应，CDF 网格在姿势中间撕裂脚底、耳朵和尾巴，并拉扯五官；非方形原稿与眼睛被统一拉伸到 280×230。截图见 `build/validation/art-audit-20261009/baseline/`。

此前鼻部位移和点击锚点检查仅证明锚点连续，不能证明身体或五官画面正确；480 帧与 3934 项历史通过结果不能作为旧形变方案视觉合格的证据。

## 安全绘制路径

- 移除跨姿势 CDF 网格、顶点 UV 编码及混合 shader。身体始终只绘制一张完整原稿；不交叠两只猪，也不拉伸原图轮廓。
- 所有身体裁区记录真实 canvas 比例，鼻部、五官和装扮使用同一等距坐标系和刚性矩阵。整猪只做幅度受限的旋转、平移、均匀呼吸缩放；鼻部输入使用实际同一变换。
- 姿势变化先轻微预备、闭眼换关键姿势，再缓动落稳。鼻部路径和整体尺度连续，身体轮廓在闭眼处换关键图，并不是逐关节连续起卧。转身在短暂眨眼中换朝向，横向倍率只为 +1 或 -1，绝不经过零。
- 保留动作时钟与积分呼吸相位；新请求只保留最新待呈现目标。隐藏、减少动态、桌面后台、安静/勿扰、拖动时仍冻结自主表现，不改养成模拟或奖励。
- 原稿四帧继续保留给静态检查，运行只用首帧，避免播放独立生成原稿造成抽动。嘴继续独立绘制，趴下/遮挡身体和默认豆豆眼隐藏嘴。眼珠不添加白色。
- 眼镜用真实两眼锚点定位；围巾/领结不落到脚底外。身体已有特殊衣装时不重复叠穿。
- 房间、氛围和小剧场背景按等比覆盖裁切；表情相册、行为道具按等比适配。家具、零食、相框图集用主要透明连通域测量裁区，排除相邻格残片，不重绘 PNG 字节。
- 五官直接在共同姿势矩阵下绘制原坐标矩形，避免为每个 1×1 图元复合额外缩放造成离屏截图重挂载的浮点光栅差异。

## 2026-10-09 嘴部安全区域修正

鼻子下方居中不等于嘴一定还在脸上。实际联系表中，探头姿势的嘴进入前爪区域，抱头姿势脸部下缘空间不足，王者形态的嘴与一体披风衣领混在一起。此前仅检查嘴的中心，没有限制完整嘴部矩形，因此没能覆盖这个问题。

这三类姿势现在与趴下等遮挡姿势一样隐藏嘴；默认豆豆眼继续无嘴。其余表情嘴独立保留，围绕鼻部真实中线定位，均匀缩至原相对大小的 65%，保持轮廓比例和黑色原稿。四个原稿帧各自记录鼻下脸部安全矩形，静态和动态绘制共同调用同一完整矩形检查；数据不完整或嘴超出安全区时不画嘴，而不是让它落到爪子、衣服或透明区域。猪主体、眼睛锚点及 PNG 字节均未更改。

`python3 tools/run_art_visual_audit.py --only mouth --output <目录>` 覆盖 12 姿势 × 8 表情 × 4 帧规则，以及左右转身、连续换姿势、房间脚底锁定和普通桌宠变换，真实截图与失败复现保留在 `build/validation/mouth-anchor-20261009/`。本次先完成修改，再集中验证相关范围，不重复全部 UI 美术流水线。

最终嘴部专项 4555 项和 35 项相关 Python 检查通过；headless 导入、7064 项核心、Full/Demo 节奏与 75 项 Demo profile 通过。串行导出/加载 Full/Demo ZIP、本地签名 Mac 预览及隔离存档的原生 GUI 启动通过，当前源码身份为 `7e80e72c39eb2834cc926a217f071422847d89a24ea2dbcc99eb3c1882d8f603`，启动限制和普通/QA PCK 区分见本轮 `packages/preview.json`。最终资源门禁仍按预期失败，Windows 实机验收没有新增通过项。

## 已知边界

这次解决比例错误、撕裂、重影和零宽度转身，不声称已经拥有手工补齐的逐帧起卧/转身动画。需要更自然的关节动作时，应制作解剖对应的分层身体或专门桥接帧，不能再用不同原稿轮廓强行插值。现有装扮原稿仍含卡通耳朵装饰，不视为新增身体肢体；身体本身不替换。

19 张现有 PNG 字节保持不变，网格数据从约 240 KiB 缩小到 42,878 字节，去掉每角色 627 顶点网格和双原稿 shader。音频仍静音开发占位，最终资产门禁继续失败；Windows 透明/穿透、原生拖动、触控、多 DPI 和长时间性能没有实机验收。

## 本机验证结果

最终结果和构建身份以本轮证据日志为准。集中检查包括 Godot headless 导入、7064 核心断言、Full/Demo 节奏、内容与相关 Python 检查，Full/Demo ZIP 串行导出、包结构和隔离 HOME 启动，以及 Mac universal 本地签名/原生 GUI 启动。Windows EXE 和旧 Downloads 试玩包没有被这轮验证 ZIP 或 Mac 预览替换，历史发行候选清单不代表当前运行时。

- 2121 项真实美术审计、3934 项连续性/保护检查通过，480 个实际不同帧；常规姿势鼻部最大单步位移 1.765 像素，渲染鼻孔到点击锚点最大误差 0.447 像素。数字仅作为锚点证据，另外人工检查全部联系表中的身体轮廓与五官。
- 2481 项真实 UI 检查通过，含五档桌宠、三语控制布局、主动输入与低干扰保护、透明独立猪、舞台冻结及拍照同时切换窗口/桌面。发现离屏重挂载时一只眼的 18 像素有最多 2 色阶差异，改为共同姿势矩阵绘制原矩形后恢复逐字节相等；没有放宽照片断言。
- 113 项真实上下文检查通过，补查全部家具在房间中的绘制、五种氛围的实际叠加、三个房间配色及三种相框装载真实小剧场照片。离线截图目录为 `build/validation/art-audit-20261009/index.html`。
- 30 项相关 Python 检查及内容/生成素材检查通过。Full/Demo 节奏保持 1800 秒 Demo、38165 秒正式熟悉度 10；最终资源门禁依旧按预期失败。
