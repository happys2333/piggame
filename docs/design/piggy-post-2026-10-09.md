# 猪咪来信：累计点数收藏奖励

- 每只猪按自己累计获得的点数自动寄信，阈值为 100、300、600、1200、2500、5000、9000、15000。消费不减进度；初始 70 点赠送不计入。永久内容 ID 独立于排序、猪名及余额。
- 八张原图来自用户授权的 PigHub 表情库，搭配本地化信件与当前猪名。原图中文不翻译、不裁切、不拉伸；不替换基础猪、动态五官、身体或家具。来源、尺寸与原字节哈希见 `game/assets/final/pighub/source.json` 和 `LICENSES/PigHub/SOURCE.md`。
- 信箱位于相册第五页「猪咪来信」。锁定时不加载图片，只显示累计阈值；收到后翻开、查看落款日期，并永久珍藏。桌宠既有气泡可返回小屋信箱，右键菜单也有手动入口；单猪模式不增加额外浮窗。
- 收信完全离线，不发送真实邮件、不需要账号、不采集玩家资料、不访问 PigHub。支持后台、睡眠/唤醒结算、离线收入、独立多住客及 Demo→正式版存档迁移。未读点和已有桌宠气泡为唯一自动呈现；其他游戏前台、安静/勿扰或频率关闭时不弹窗、不发声、不抢焦点，不解禁置顶/漫步。
- 明信片只增加收藏，不另奖点数/熟悉度，不参与成就、结局或 Demo 完成条件。不惩罚离开、不设签到、不限时、不要求及时拆信。最后几封为长期陪伴收藏，不延长 8–20 小时的核心养成或 20–40 分钟 Demo 目标。
- schema 4 新增可选 `earned_points`、`received_postcards`（ID→寄达时间）和 `read_postcards`；旧档保守迁移为 `max(余额−70, 0)`。历史花费无法从旧档真实恢复，不伪造累计值；之后所有正收入正常累计。各住客独立迁移，不继承上一只的信箱。
- 寄达先参与原有原子存档，成功后才发通知；失败恢复新寄达记录，保留已挣点数待重试。拆信通过 `GameSession` 的完整事务，写入失败保持未读。重复保存/重载不会重复发信，两个轮换备份与机器设置隔离不变。
- 原图不是 image_gen 输出，也不是用户原创。项目所有者授权使用并不等于独立核验每位作者权属；权利核验及最终发行批准仍待完成，最终素材门禁保持未就绪。音乐/音效继续静音开发占位。
