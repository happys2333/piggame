# 桌宠仅显示猪咪，右键操作

2026-10-10 用户明确取消桌面侧栏方案。此决策替代之前的可切换控制条／独立猪模式，不继续增大或保留侧栏。

## 当前实现

- 桌面只显示完整猪咪，以及玩家主动使用的场景物品；不创建常驻按钮条、侧栏、来信气泡或相应的透明点击区域。五档猪咪尺寸均不预留侧栏宽度。
- 右键猪咪打开菜单，包含返回小屋、相册／待看回忆、猪咪来信、物品互动、专注／安静／勿扰、焦点置顶、暂停、普通小窗、陪伴设置、最小化和退出。大小与停靠收进子菜单。
- 菜单字号至少 18 px，跟随 100%–150% 界面缩放，不随猪咪缩到 50% 而缩小。字体和图标继续使用原有离线授权资源，没有重新生成猪咪或引入新美术。
- 菜单使用 Godot 渲染的原生独立弹出窗口，避免被小猪的透明宿主窗口裁切。菜单图标明确使用深色调制，不再出现白色图标落在纸白背景上的问题。
- 来信／回忆数量只静默更新菜单，不自动打开菜单、显示浮层或抢焦点。原防打扰、安静／勿扰与养成逻辑不变。
- 不透明普通小窗仍有系统标题栏，但没有游戏侧栏；仍能右键操作，Esc 返回完整小屋。透明能力缺失时同样保留普通窗口回退。
- 旧机器设置 `desktop_pig_only=false` 不会重新显示侧栏。保存仍经 GameSession，养成档与机器设置分离；没有新 save schema。

最终串行 GUI 证据在 `build/validation/desktop-context-20261010/serial-ui/`：637 项通过，45 种尺寸／语言组合及 3 张菜单、3 张普通小窗共 51 张实际 PNG。此前初轮误把弹出菜单的内部控件计成常驻侧栏，修正测试仅检查控制器直接创建的常驻节点；`final-ui` 中一次菜单可见性失败发生于隔离原生包同时启动期间，未放宽断言，随后在无并行 GUI 启动时串行复测通过。所有诊断日志保留，不把这些失败轮次称为通过。

核心 7080、拖动 85、Full／Demo 节奏、实际 Demo profile 75、明信片规则、Python 162、内容和 226 视觉门禁通过；帮助文字最终同步 Esc 返回小屋后，内容与字体覆盖窄检查再次通过。没有反复执行全量 UI smoke。

新版 Full／Demo ZIP 已串行导出／校验／隔离加载；Mac 预览签名校验和独立存档版本启动通过。`build/validation/desktop-context-20261010/packages/mac-native.zip` 是可打开的 Mac 本地预览；资源验证 ZIP 不是 Windows EXE，本轮未更新旧 Windows 候选。包、当前运行输入和最后串行 GUI 的源树 SHA-256 一致：`69a0f6cbf8d74806aa592f5812743bc186f01202fc9381412c3f49a1d9a626aa`。玩家旧版未被终止或与新版同时启动；使用新包前须先正常退出旧版，避免两个存档写入进程。
