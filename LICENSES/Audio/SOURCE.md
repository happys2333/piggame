# Generated interaction sound effects

The project owner commissioned ComfyUI Cloud Run audio generation and approved sound-effect integration on 2026-10-12, explicitly declining BGM. The game includes 13 selected one-shot mono WAV effects generated using Stable Audio 3 Medium. No music or continuous ambience ships or plays. Runtime processing includes trimming, fades, mono conversion and conservative peak normalization; originals are unchanged in the excluded development candidate archive.

Prompts, seeds, provider/model identity, embedded-workflow verification, original and processed hashes, processing and measurements are recorded in `game/assets/audio/source.json`. The development archive is `audio_candidates/2026-10-12/`; it is not exported. Cloud model-weight hashes were not exposed. These are generated assets, not user-supplied original recordings.

The owner reports commercial entitlement through their Cloud subscription. This is the stated authorization basis, not independent verification of provider terms or final-release rights approval. Physical output, subjective listening, Windows audio/device compatibility and final release rights review remain pending. Integration approval is not final-release acceptance.
